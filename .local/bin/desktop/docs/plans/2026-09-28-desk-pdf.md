# desk pdf — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline, choisi par l'utilisateur : « implémente tout »). Steps use checkbox (`- [ ]`) syntax.

**Goal:** boîte à outils PDF hors ligne (16 outils PDF24) : moteur Python partagé par rofi, Dolphin et une fenêtre PyQt6.

**Architecture:** `pdf/ops.py` (sans Qt) implémente chaque outil et retourne les chemins créés ; `pdf/tools.py` décrit les outils et leurs options (source unique pour rofi, CLI et fenêtre) ; `pdf/cli.py` expose le tout ; `desk-pdf` (bash, `lib.sh`) pose les questions via rofi de façon générique à partir du schéma d'options ; la fenêtre (`app.py`, `organizer.py`, `editor.py`, `signature.py`) réutilise `ops`.

**Tech Stack:** Python 3 · PyMuPDF 1.28 · pikepdf 10.14 · img2pdf 0.6 · Ghostscript 10.08 · qpdf 12.4 · poppler (pdftoppm, pdfimages, pdftotext) · PyQt6 6.11 + QtWebEngine · python-markdown · LibreOffice (optionnel) · bash + rofi · pytest 9.

**Spec:** `~/.local/bin/desktop/docs/specs/2026-09-28-desk-pdf-design.md`

**Écart assumé au format du skill :** l'exécution est inline, juste après. Le plan donne le code complet des tests (qui fixent le comportement) et les signatures exactes. Le code d'implémentation est écrit directement dans les fichiers pendant l'exécution, pour ne pas écrire le programme deux fois.

## Global Constraints

- Libellés bilingues « français ‖ english » ; langue courante lue dans `~/.local/state/desk/lang` (`fr` | `en`, défaut `en`).
- Sorties à côté de l'original, `<stem>-<suffixe>.pdf`, puis `-2`, `-3`… ; jamais d'écrasement ; écriture atomique (`os.replace`).
- Mots de passe : jamais en argument, jamais dans un log ni une notification (`--password-stdin`).
- Codes de sortie du CLI : 0 = OK (chemins créés sur stdout, un par ligne) · 1 = erreur (message sur stderr) · 2 = usage · 3 = mot de passe requis ou incorrect.
- Fichiers existants modifiés seulement avec une sauvegarde `*.bak-2026-09-28-pdf` : `~/.config/hypr/desktop-leader.conf`, `actions.sh`, `README.md`.
- Leader **P** = `desk leader pdf`, **E** = `desk leader project` ; même chose pour SUPER+P et SUPER+E dans le submap.
- Pas de git dans `~/.local/bin/desktop` : pas d'étape de commit (dotfiles : commit seulement sur OK explicite).
- Tests : `cd ~/.local/bin/desktop && python3 -m pytest pdf/tests -q`.

### Task 2: ops — opérations sur les pages et sécurité

**Files:** Create `pdf/ops.py`, `pdf/tests/test_ops_pages.py`

**Interfaces (Produces):**
- `class OpError(Exception)` (message lisible, déjà traduit) ; `class PasswordError(OpError)` (attribut `wrong: bool`)
- `open_pdf(src: Path, password: str | None = None) -> pikepdf.Pdf` : lève `PasswordError` ; ouvre les PDF abîmés (réparation par qpdf) ; ajoute un avertissement à `ops.WARNINGS: list[str]` si pikepdf signale une réparation.
- `@dataclass PageRef(src: Path, index: int, rotate: int = 0)`
- `build(pages: list[PageRef], dest: Path, passwords: dict[Path, str] | None = None) -> Path` : assemble des pages de plusieurs PDF (organiseur, tri) ; écriture atomique.
- `merge(files, password=None) -> list[Path]` (PyMuPDF : liens + un signet par fichier) → `<premier>-merged.pdf`
- `split(src, mode="each"|"every"|"ranges", n=1, ranges="", password=None) -> list[Path]` → dossier `<stem>-split/<stem>-001.pdf`…
- `rotate(src, angle=90, ranges="", password=None)` → `-rotated`
- `remove_pages(src, ranges, password=None)` → `-removed` (`OpError` si toutes les pages sont supprimées)
- `extract_pages(src, ranges, password=None)` → `-extract`
- `reverse(src, password=None)` → `-reordered`
- `protect(src, password_new, forbid_print_copy=False, password=None)` → `-protected` (AES-256, R=6)
- `unlock(src, password=None)` → `-unlocked`
- Toutes retournent `list[Path]` (les chemins créés : un fichier, ou le dossier pour split).

```python
# pdf/tests/test_ops_pages.py
import pikepdf, pytest
from conftest import make_pdf, page_texts
from pdf import ops

def test_merge(tmp_path):
    a = make_pdf(tmp_path / "a.pdf", 2, "A{}"); b = make_pdf(tmp_path / "b.pdf", 1, "B{}")
    [out] = ops.merge([a, b])
    assert out.name == "a-merged.pdf"
    assert page_texts(out) == ["A1", "A2", "B1"]
    import fitz
    assert [e[1] for e in fitz.open(out).get_toc()] == ["a", "b"]

def test_split_each_every_ranges(pdf3):
    [d] = ops.split(pdf3, "each")
    assert sorted(p.name for p in d.iterdir()) == ["doc-001.pdf", "doc-002.pdf", "doc-003.pdf"]
    [d2] = ops.split(pdf3, "every", n=2)
    assert [len(page_texts(p)) for p in sorted(d2.iterdir())] == [2, 1]
    [d3] = ops.split(pdf3, "ranges", ranges="1,2-3")
    assert [page_texts(p) for p in sorted(d3.iterdir())] == [["PAGE 1"], ["PAGE 2", "PAGE 3"]]

def test_rotate_subset(pdf3):
    [out] = ops.rotate(pdf3, 90, "2")
    with pikepdf.open(out) as p:
        assert [int(pg.obj.get("/Rotate", 0)) for pg in p.pages] == [0, 90, 0]

def test_remove_extract_reverse(pdf3):
    assert page_texts(ops.remove_pages(pdf3, "2")[0]) == ["PAGE 1", "PAGE 3"]
    assert page_texts(ops.extract_pages(pdf3, "3,1")[0]) == ["PAGE 3", "PAGE 1"]
    assert page_texts(ops.reverse(pdf3)[0]) == ["PAGE 3", "PAGE 2", "PAGE 1"]
    with pytest.raises(ops.OpError):
        ops.remove_pages(pdf3, "1-3")

def test_build_across_files(tmp_path):
    a = make_pdf(tmp_path / "a.pdf", 2, "A{}"); b = make_pdf(tmp_path / "b.pdf", 1, "B{}")
    out = ops.build([ops.PageRef(b, 0, 180), ops.PageRef(a, 1)], tmp_path / "x.pdf")
    assert page_texts(out) == ["B1", "A2"]
    with pikepdf.open(out) as p:
        assert int(p.pages[0].obj.get("/Rotate", 0)) == 180

def test_protect_unlock(pdf3):
    [prot] = ops.protect(pdf3, "s3cret", forbid_print_copy=True)
    with pytest.raises(pikepdf.PasswordError):
        pikepdf.open(prot)
    with pikepdf.open(prot, password="s3cret") as p:
        assert p.encryption.R == 6
    with pytest.raises(ops.PasswordError) as e:
        ops.unlock(prot)
    assert not e.value.wrong
    with pytest.raises(ops.PasswordError) as e:
        ops.unlock(prot, "bad")
    assert e.value.wrong
    [un] = ops.unlock(prot, "s3cret")
    assert not pikepdf.open(un).is_encrypted
    assert page_texts(un) == ["PAGE 1", "PAGE 2", "PAGE 3"]

def test_encrypted_input_to_other_op(pdf3):
    [prot] = ops.protect(pdf3, "pw")
    with pytest.raises(ops.PasswordError):
        ops.rotate(prot, 90)
    [out] = ops.rotate(prot, 90, password="pw")
    assert not pikepdf.open(out).is_encrypted

def test_no_overwrite(pdf3):
    a = ops.reverse(pdf3)[0]; b = ops.reverse(pdf3)[0]
    assert a.name == "doc-reordered.pdf" and b.name == "doc-reordered-2.pdf"
```

### Task 3: ops — compression, images, texte, conversion

**Files:** Modify `pdf/ops.py` ; Create `pdf/web.py`, `pdf/tests/test_ops_media.py`

**Interfaces (Produces):**
- `compress(src, level="light"|"recommended"|"strong", password=None) -> list[Path]` : gs `-dPDFSETTINGS=/printer|/ebook|/screen`, puis `qpdf --object-streams=generate --recompress-flate` ; retourne `[]` si le résultat n'est pas plus petit (rien n'est écrit). `ops.LAST_GAIN: tuple[int, int] | None` = (taille avant, taille après).
- `images_to_pdf(images, fit="a4"|"image") -> list[Path]` → `<premier>-images.pdf` ; webp/heic/gif/bmp/tiff convertis en PNG par `magick` dans un dossier temporaire.
- `pdf_to_images(src, fmt="png"|"jpg", dpi=150, ranges="", password=None)` → dossier `<stem>-images/`
- `extract_images(src, password=None)` → dossier `<stem>-extracted/` ; `OpError` si aucune image.
- `to_text(src, password=None)` → `<stem>.txt` (`pdftotext -layout`)
- `convert(src) -> list[Path]` : `.pdf` → `to_text` ; `.html/.htm/.md/.markdown/.txt` → `web.render` ; formats Office (`OFFICE_EXT`) → `soffice --headless --convert-to pdf -env:UserInstallation=file://<tmp>` (délai 120 s) ; `OpError` « installer libreoffice-fresh » si `soffice` est absent.
- `webpage(source: str, directory: Path = ~/Downloads) -> list[Path]` → `<titre-nettoyé>.pdf` (via `web.render`).
- `web.render(source: str, out: Path, timeout: int = 30) -> str` : retourne le titre de la page ; lancé dans un sous-processus `python3 -m pdf.web <source> <out>` (sortie : titre sur stdout) pour ne jamais imbriquer de boucle Qt ; `QT_QPA_PLATFORM=offscreen`.

### Task 5: module bash `desk-pdf` + Dolphin

**Files:** Create `desk-pdf`, `~/.local/share/kio/servicemenus/desk-pdf.desktop`, `desk-pdf-images.desktop`, `desk-pdf-convert.desktop` (tous `chmod +x`)

**Interfaces (Consumes):** CLI de la tâche 4. **Produces :** `desk pdf` (menu), `desk pdf <tool> [fichiers…]`, `desk pdf gui [--tool t] [fichiers…]`, `desk pdf run <id>` / `--list` (palette : `ACTIONS` = `open|Boîte à outils…` + un id par outil), `desk pdf cli …` (moteur brut), `desk pdf notify-done chemin…` (notification de fin avec boutons, réutilisée par la fenêtre).

Comportement de `desk pdf <tool> [fichiers…]` :
1. Outil `editor`/`sign`/`organizer` (sauf rearrange lancé par Dolphin avec un menu « Inverser / Ouvrir l'organiseur ») → `setsid -f python3 -m pdf.cli gui --tool <id> fichiers…`.
2.
